Actividades · U07 Robótica y control

12 actividades en 4 bloques.

Bloque 1 · Sistemas de control

1Entrada-proceso-salida

Identifica entrada, proceso y salida en cada sistema:
  1. Aire acondicionado con mando
  2. Cinta transportadora con sensor de presencia
  3. Persiana motorizada con temporizador

1. Entrada: temperatura deseada (mando) + temperatura actual. Proceso: comparar y decidir. Salida: aire frío/calor.
2. Entrada: presencia de objeto. Proceso: encender motor un tiempo. Salida: cinta se mueve.
3. Entrada: hora actual. Proceso: comparar con horario programado. Salida: motor sube/baja.

2Lazo abierto o cerrado

Para cada sistema, ¿abierto o cerrado? Razona.
  1. Tostadora con temporizador
  2. Frigorífico con termostato
  3. Aspersor automático de riego sin sensor
  4. Coche con control de crucero adaptativo
  5. Lavadora moderna que detecta peso de la carga

1. Abierto (cuenta tiempo, no mide tostado). 2. Cerrado (sensor de temperatura). 3. Abierto (no mide humedad). 4. Cerrado (mantiene distancia con el coche delante = sensor). 5. Cerrado (mide peso → ajusta agua y giros).

3Convertir abierto en cerrado

Una calefacción de garaje funciona en lazo abierto: se enciende a las 7:00 y se apaga a las 9:00 todos los días. Propón cómo convertirla en lazo cerrado y qué ventajas tendría.

Añadir un sensor de temperatura y un termostato: la caldera se enciende cuando la temperatura baja del valor objetivo y se apaga cuando se alcanza. Ventajas: ahorra energía (no calienta más de lo necesario), mantiene confort constante (no hace frío al rato de apagarse), se adapta a temperaturas exteriores cambiantes.

Bloque 2 · Robots

4Anatomía del robot

Para un robot aspirador, indica qué sensores y actuadores tiene y para qué los usa.

Sensores: ultrasonidos (evita choques), IR (detecta paredes y escalones para no caer), giroscopio (orientación), encoders en ruedas (saber cuánto ha andado), sensor de polvo (carga del depósito).
Actuadores: 2 motores DC (ruedas, velocidad variable), motor de cepillo, motor de aspirado (turbina), zumbador (señales sonoras), LEDs (estado), motor de carga (volver a la base).

5Sense-Think-Act

Describe el ciclo Sense-Think-Act para una barrera de paso a nivel.

Sense: sensor detecta tren acercándose por las vías.
Think: «Si el tren se acerca a menos de X metros → bajar barrera».
Act: motor baja la barrera, enciende luces rojas y zumbador.
Después: Sense (tren pasó) → Think («todo despejado») → Act (subir barrera, apagar luces).

6Robot vs automatismo

Indica si cada máquina es robot o solo automatismo:
  1. Impresora 3D
  2. Aspirador Roomba
  3. Microondas
  4. Drone autónomo
  5. Lavadora

1. Automatismo (ejecuta órdenes pero no decide). 2. Robot (percibe, decide, actúa). 3. Automatismo. 4. Robot (decide ruta evitando obstáculos). 5. Automatismo (aunque sea con feedback). Clave: el robot decide en base a sensores, no solo ejecuta un guion.

Bloque 3 · Arduino

7Lee el código

¿Qué hace este programa?
int led = 9; void setup(){ pinMode(led, OUTPUT); } void loop(){ for(int i=0;i<=255;i+=5){ analogWrite(led,i); delay(20); } for(int i=255;i>=0;i-=5){ analogWrite(led,i); delay(20); } }

Efecto respiración: el LED se enciende gradualmente desde apagado a brillo máximo (1 s aprox.) y luego se apaga gradualmente. Y vuelta a empezar. Usa PWM (analogWrite).

8Encuentra el error

Un programa debería encender un LED cuando se pulsa un botón. No funciona. ¿Dónde está el error?
int led = 13, boton = 2; void setup(){ pinMode(led, INPUT); pinMode(boton, OUTPUT); } void loop(){ if (digitalRead(boton) == HIGH) digitalWrite(led, HIGH); else digitalWrite(led, LOW); }

Los pinModes están invertidos: el LED debería ser OUTPUT (salida) y el botón INPUT_PULLUP (entrada con resistencia interna). Lo correcto:

pinMode(led, OUTPUT); pinMode(boton, INPUT_PULLUP); if (digitalRead(boton) == LOW) // pulsado = LOW con PULLUP

9Diseña el programa

Diseña un programa Arduino para una alarma anti-intrusos: si un sensor IR detecta movimiento Y la alarma está activada (interruptor), suena un zumbador y parpadea un LED.
int ir = 2, sw = 3, buzz = 8, led = 9; void setup(){ pinMode(ir, INPUT); pinMode(sw, INPUT_PULLUP); pinMode(buzz, OUTPUT); pinMode(led, OUTPUT); } void loop(){ if (digitalRead(sw)==LOW && digitalRead(ir)==HIGH){ tone(buzz, 1000); digitalWrite(led, HIGH); delay(200); digitalWrite(led, LOW); delay(200); } else { noTone(buzz); digitalWrite(led, LOW); } }
Bloque 4 · IoT

10Aplicaciones IoT cotidianas

Lista 5 dispositivos IoT que conozcas en tu entorno (casa, familia, ciudad) y explica qué datos recogen y para qué.

Ejemplos típicos: Alexa/Google Home (voz → comandos), Apple Watch (frecuencia cardíaca → salud y deporte), termostato Nest (temperatura y presencia → calefacción optimizada), cámara de seguridad WiFi (vídeo → vigilancia), persiana motorizada (horario → confort), contadores inteligentes de luz/agua (consumo → facturación y detección de fugas).

11Privacidad IoT

Imagina que regalas a tus padres una báscula IoT, una cámara, un altavoz inteligente y una bombilla WiFi. Reflexiona en 6-8 líneas sobre qué riesgos de privacidad y seguridad pueden tener.

Riesgos: Báscula: comparte peso/IMC con la app, podrían venderlo a aseguradoras. Cámara: si la contraseña es débil, cualquiera puede mirar; bots Mirai (2016) usaron cámaras para tumbar internet. Altavoz: micrófono permanente, ya hay casos de grabaciones revisadas por humanos. Bombilla: parece tonta, pero si la app envía datos sin cifrar, alguien puede espiar tus hábitos (cuándo estás en casa).
Buenas prácticas: cambiar contraseñas por defecto, leer términos, actualizar firmware, mantenerlos en una red WiFi separada de la principal.

12Imagina y diseña

Diseña un dispositivo IoT que solucione un problema cotidiano de tu entorno (escuela, casa, barrio). Define: nombre, qué hace, qué sensores y actuadores usa, qué datos envía a la nube, y al menos un riesgo ético o de seguridad.

Ejemplos: macetero inteligente (sensor humedad + bomba agua → riega solo cuando hace falta + app que avisa), comedero gato (sensor peso + servo dispensador → ración programada), pulsera niño (GPS + botón pánico → padres saben dónde está), buzón de paquetería (sensor IR → notifica cuando llega Amazon). Riesgo común: si alguien hackea, sabe rutinas familiares.
