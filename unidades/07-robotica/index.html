Unidad 07

🤖 Robótica

⏱️ Duración estimada: 12-14 sesiones

📖 Saber

  • Sistemas de control: lazo abierto y lazo cerrado, realimentación
  • Sensores: posición, distancia, luz, temperatura, presencia, fuerza
  • Actuadores: motores DC, paso a paso, servomotores; relés
  • Microcontroladores (Arduino o similar): pines digitales/analógicos, PWM
  • Programación: estructuras de control, librerías, comunicación serie
  • Robots móviles, manipuladores y antropomorfos: cinemática básica

🛠️ Hacer

  • Conectar y programar un sensor para que active un actuador
  • Diseñar y construir un robot móvil sencillo (seguidor de línea, evita obstáculos)
  • Implementar control PID básico para regular la velocidad de un motor
  • Documentar el robot con esquema, código comentado y vídeo de funcionamiento

✅ Evaluar

  • El robot cumple su función especificada
  • Se distingue lazo abierto de lazo cerrado en el diseño
  • El código está estructurado y comentado
  • Se aplican normas de seguridad eléctrica
