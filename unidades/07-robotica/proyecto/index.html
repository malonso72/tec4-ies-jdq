🚀 Robot con Arduino

Construye y programa un dispositivo Sense-Think-Act que resuelva un problema real.

1La idea

Tu equipo (parejas) detecta una necesidad y construye un robot/dispositivo electrónico con Arduino que la resuelva: al menos 1 sensor + 1 actuador + regla lógica programada.

Duración: 5-6 sesiones de aula + trabajo en casa. Entrega: dispositivo físico + .ino + memoria PDF + vídeo de 60-90 s + defensa oral 5 min.

2Ideas de partida

♻️ Cubo separador de residuos

Sensor de color o capacidad + servo abre la tapa correcta.

🌡️ Termo-alarma

NTC + LED rojo + zumbador cuando supera umbral.

💡 Farola pública

LDR enciende LED cuando oscurece.

🚪 Puerta auto

Sensor IR + servo abre puerta corredera al detectar persona.

🤖 Robot evita obstáculos

Ultrasonidos + 2 motores DC con chasis impreso 3D.

📊 Estación meteo

DHT11 + pantalla LCD muestra T y humedad.

🌱 Macetero inteligente

Sensor humedad + LED avisa cuando hay que regar.

🎮 Tu idea

Habla con el profe para validar viabilidad.

3Fases

🎯 1. Definir

Qué hace, para quién, qué sensores y actuadores.

📐 2. Esquema

Esquema eléctrico con todos los componentes.

🔌 3. Montaje

Protoboard con cables y componentes.

💻 4. Programa

Pseudocódigo → Arduino IDE → upload.

🧪 5. Probar

Funciona en condiciones reales.

🔁 6. Iterar

Mejora al menos UNA cosa.

📦 7. Carcasa

Cartón, impresión 3D, MDF láser.

🎤 8. Defender

5 min demo + PDF + vídeo.

💡 Recursos recomendados: Arduino IDE, Tinkercad Circuits (simulador online), GitHub para compartir el .ino con el equipo, biblioteca Servo, NewPing (ultrasonidos), DHT (sensor temperatura/humedad).
⚠️ Seguridad: nunca conectes Arduino directamente a 230 V (usa relé). Cuidado con cortocircuitos (siempre conectar GND antes que VCC). Si huele a quemado, desconectar inmediatamente.
