U07 · Robótica, control e Internet de las Cosas

Cómo las máquinas pueden percibir, decidir y actuar de forma autónoma, y cómo se conectan entre sí para crear el mundo «inteligente» que ya nos rodea.

⏭️

Conexión Bachillerato: el bloque F de TECI II profundiza con diagramas de bloques, función de transferencia, lazos de control PID y estabilidad de sistemas.

1. Sistema técnico: entrada, proceso, salida

Cualquier sistema técnico tiene tres partes:

📥 Entrada

Datos que recibe: temperatura ambiente, pulsación del usuario, distancia a obstáculo.

⚙️ Proceso

Lo que decide hacer con esos datos. La "inteligencia" del sistema.

📤 Salida

Lo que hace en consecuencia: encender el LED, mover el motor, mostrar texto.

Ejemplos: tu móvil (toque → procesador → respuesta visual), un horno (temperatura programada → calienta o no → genera calor), un robot (sensor → decisión → motor).

2. Lazo abierto y lazo cerrado

📡 Lazo abierto

El sistema ejecuta una orden sin comprobar el resultado. Ejemplo: la lavadora ejecuta el ciclo sin saber si las prendas están limpias.

🔄 Lazo cerrado (con feedback)

Hay un sensor que mide la salida y la compara con el objetivo, corrigiendo si es necesario. Ejemplo: el termostato apaga la calefacción cuando llega a la temperatura deseada.

🔁

El feedback (realimentación) es el ingrediente que hace «inteligente» a un sistema: le permite reaccionar a la realidad en lugar de seguir un guion ciego.

4. ¿Qué es un robot?

Un robot es una máquina automática con tres ingredientes esenciales:

👁️ Sensores

Para percibir el entorno: cámaras, ultrasonidos, IR, micrófonos, fuerza.

🧠 Cerebro

Un microcontrolador (Arduino, micro:bit) o un procesador completo (Raspberry Pi) que toma decisiones.

💪 Actuadores

Para actuar: motores, servomotores, pinzas, voz, pantallas.

Sin sensor, no es robot: es solo automatismo. Sin actuador, es solo instrumento de medida. Sin cerebro, es solo conexión directa.

5. Sense-Think-Act (Percibir-Decidir-Actuar)

El bucle fundamental que ejecuta cualquier robot:

  1. Sense (Percibir): leer sensores.
  2. Think (Decidir): aplicar reglas o condiciones.
  3. Act (Actuar): mover actuadores.

Y vuelta a empezar. En Arduino, este bucle es exactamente la función loop().

EJEMPLO
Robot aspirador

Sense: el sensor de ultrasonidos detecta una pared a 10 cm.
Think: «Si distancia < 15 cm → parar y girar».
Act: motor izquierdo gira al revés, el robot rota a la derecha.
Sense de nuevo: ¿hay pared? No. Act: seguir adelante.

9. Estructura de un programa Arduino

// Variables globales
int led = 13;

void setup() {
  // UNA VEZ al encender
  pinMode(led, OUTPUT);
}

void loop() {
  // SIN PARAR
  digitalWrite(led, HIGH);
  delay(500);
  digitalWrite(led, LOW);
  delay(500);
}

Las 4 instrucciones básicas:

  • digitalRead(pin) · lee HIGH/LOW
  • digitalWrite(pin, valor) · pone pin a HIGH o LOW
  • analogRead(pin) · lee 0-1023 (entrada analógica)
  • analogWrite(pin, valor) · salida PWM 0-255

10. Ejemplos prácticos

EJEMPLO 1
Farola automática
int ldr = A0;
int led = 9;

void setup(){pinMode(led, OUTPUT);}

void loop(){
  int luz = analogRead(ldr);
  if (luz < 400) digitalWrite(led, HIGH); // oscuro
  else          digitalWrite(led, LOW);
}

11. Internet de las Cosas (IoT)

El IoT (Internet of Things) es la conexión a internet de objetos cotidianos: bombillas, termostatos, frigoríficos, neveras, cerraduras, coches... Cada uno con su sensor, su pequeño procesador y conectividad WiFi/4G/Bluetooth.

Cómo funciona

  1. El dispositivo IoT recoge datos con sus sensores.
  2. Los envía por internet a un servidor en la nube.
  3. El servidor los analiza, los muestra al usuario y, si procede, envía órdenes de vuelta.
  4. El dispositivo ejecuta las órdenes.
EJEMPLO
Termostato Nest

El termostato mide temperatura y aprende tus hábitos. Cuando sales de casa (detecta tu móvil ausente vía la app), baja la calefacción. Cuando estás cerca, vuelve a subir. Puedes encenderla desde el móvil al volver de viaje.

12. Aplicaciones y retos del IoT

Aplicaciones

🏠 Hogar conectado

Alexa, Google Home, Philips Hue, cámaras de seguridad.

🚗 Coche conectado

Mantenimiento predictivo, navegación con tráfico real.

🌾 Agricultura

Riego automatizado según humedad, monitorización de cultivos.

🏥 Salud

Pulseras, marcapasos conectados, monitorización remota.

🏭 Industria 4.0

Fábricas con sensores en cada máquina, predicción de averías.

🏙️ Smart cities

Alumbrado adaptativo, recogida de basura inteligente.

Retos

⚠️

El IoT plantea retos serios:

  • Seguridad: cámaras y bombillas inseguras se han usado para ataques masivos a internet (botnets Mirai 2016).
  • Privacidad: tu nevera o tu altavoz pueden saber demasiado de ti. Lee qué datos comparten.
  • Obsolescencia: cuando el fabricante deja de actualizar tu dispositivo, se vuelve inseguro o inservible.
  • Energía: miles de millones de dispositivos siempre encendidos consumen mucha electricidad.
  • Dependencia: si cae la red wifi, la "casa inteligente" se vuelve tonta.
