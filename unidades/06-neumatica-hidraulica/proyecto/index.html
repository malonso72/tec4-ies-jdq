🚀 Circuito neumático para un problema real

Diseña el esquema neumático que automatice una operación industrial sencilla.

1La idea

Tu equipo (parejas) elige un problema industrial sencillo y diseña el circuito neumático que lo resuelve: define qué hace la máquina, dibuja el esquema con símbolos normalizados (ISO 1219) y simula su funcionamiento con software libre tipo FluidSIM (o equivalente, FluidDraw).

Duración: 3-4 sesiones. Entrega: memoria PDF con esquema + simulación + defensa oral 4 min.

2Ideas de problema

📦 Empujador de cajas

Un cilindro empuja una caja al pulsar un botón.

🏷️ Etiquetadora

Una etiqueta se aplica con un cilindro al pasar producto (sensor).

🧱 Prensa con seguridad

Mando bimanual: solo prensa si se aprietan los dos pulsadores a la vez.

🚪 Puerta automática

Apertura con un sensor IR y cierre tras X segundos.

🤖 Brazo pick & place

Dos cilindros: uno para subir/bajar, otro para mover lateralmente.

3Fases

🎯 1. Definir

Qué hace, qué entradas/salidas, cuántos cilindros.

📐 2. Componentes

Selecciona cilindros, válvulas, accionamientos.

🔧 3. Esquema

Dibuja el circuito con símbolos ISO 1219.

🧮 4. Cálculos

Fuerza del cilindro (F=P·S) para la carga estimada.

💻 5. Simular

FluidSIM o equivalente. Verifica funcionamiento.

📝 6. Memoria

5-6 págs. PDF con todo.

🎤 7. Defender

4 min con esquema y simulación en pantalla.
